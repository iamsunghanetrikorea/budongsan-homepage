    게시 절차

    1. GitHub Desktop으로 저장소를 최신 상태로 가져옵니다 (Fetch / Pull).
    2. [properties.json 불러오기]로 저장소의 data/properties.json을 엽니다.
    3. 매물을 추가·수정·숨김·거래완료 처리합니다. (작업 내용은 이 브라우저에 임시 저장됩니다)
    4. [게시용 JSON 다운로드] → 받은 파일로 저장소의 data/properties.json을 교체하고, 사진은 assets/properties/에 복사합니다.
    5. GitHub Desktop에서 변경 확인 → Commit to main → Push origin.
    6. 1~3분 후 홈페이지를 새로고침하면 반영됩니다.
