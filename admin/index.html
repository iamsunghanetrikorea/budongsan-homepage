    게시 방법

    1. 처음 한 번: [GitHub 연결 설정]에서 토큰을 입력합니다.
    2. 저장소에서 불러오기로 홈페이지의 최신 매물을 가져옵니다. (연결되어 있으면 열 때 자동으로 불러옵니다)
    3. 매물을 추가·수정하고 사진을 넣은 뒤 검증 후 저장을 누릅니다. 여러 건을 한꺼번에 해도 됩니다.
    4. 홈페이지에 게시를 누르면 매물 데이터와 사진이 함께 올라가고, 1~3분 뒤 홈페이지에 반영됩니다.

    게시 전에는 이 PC 브라우저에만 임시 저장됩니다. 선택한 사진은 게시할 때 올라가므로, 게시 전에 창을 닫으면 사진을 다시 선택해야 합니다.

    GitHub 연결 설정

    게시할 저장소:

    토큰 만드는 방법 (처음 한 번)
    1. GitHub 토큰 만들기 페이지를 엽니다. (저장소 주인 계정으로 로그인)
    2. Token name: 매물 관리자, Expiration: 원하는 기간 (최대 1년, 만료되면 새로 발급)
    3. Repository access: Only select repositories → budongsan-homepage 하나만 선택
    4. Permissions → Repository permissions: Contents = Read and write, Actions = Read-only (배포 상태 확인용)
    5. Generate token → github_pat_로 시작하는 값을 복사해 아래에 붙여넣습니다.

    토큰은 이 PC의 브라우저에만 저장되며 저장소·홈페이지에는 올라가지 않습니다. 토큰은 비밀번호처럼 다른 사람에게 알려주지 마세요.
